
# CodeAlpha Object Detection & Tracking

## About the Project
This project uses Artificial Intelligence and Computer Vision to detect and track objects in videos.

## Technologies Used
- Python
- Streamlit
- YOLO (Ultralytics)
- OpenCV

## Features
- Upload a video
- Detect objects using a YOLO model
- Track objects across video frames
- Display the processed video
- Download the output video

## How to Run
1. Install the required libraries:
   `pip install -r requirements.txt`
2. Run the application:
   `streamlit run app.py`
3. Upload a video and click **Start Detection**.
