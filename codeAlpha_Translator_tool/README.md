
# AI Language Translation Tool

## About the Project
This project is a language translation web application built using Python and Streamlit.

It allows users to translate English text into different languages, including Urdu, Hindi, Arabic, French, Spanish, German, Chinese, and English.

## Technologies Used
- Python
- Streamlit
- deep-translator
- MyMemory Translation Service

## Features
- Simple and user-friendly interface
- Multiple target languages
- Translation results displayed on the page
- Error handling for translation failures

## How to Run
1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py
