# AI FAQ Chatbot

## About the Project
An FAQ chatbot built using Python and Streamlit. It uses TF-IDF vectorization and cosine similarity to find the most relevant answer to a user's question.

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- TF-IDF
- Cosine Similarity

## Features
- Interactive chat interface
- Matches questions with saved FAQs
- Provides answers about Python and AI
- Handles questions with no suitable match

## How to Run
1. Install Python.
2. Install dependencies:

   pip install -r requirements.txt

3. Start the chatbot:

   streamlit run app.py
